# components/stats

Componentes relacionados con estadísticas y gráficos:

- **weekly-chart**: Gráfico de barras con los hábitos completados cada día de la semana
- **monthly-chart**: Gráfico circular (doughnut) con el porcentaje de cumplimiento del mes
- **habit-calendar**: Calendario mensual con colores según el nivel de cumplimiento diario
