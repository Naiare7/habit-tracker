# components/habits

Componentes relacionados con la gestión de hábitos:

- **habit-list**: Muestra la lista de tarjetas de hábitos del usuario
- **habit-form**: Formulario para crear o editar un hábito
- **habit-reminders**: Gestión de alarmas/recordatorios por hábito
- **habit-suggestions**: Sugerencias de hábitos populares o predeterminados
