# components/shared

Componentes reutilizables en toda la aplicación:

- **sidebar**: Navegación lateral (escritorio) / barra inferior (móvil)
- **main-layout**: Layout principal que envuelve todas las páginas
- **celebration**: Modal animado de celebración con confeti
- **loading-spinner**: Indicador de carga con animación cozy
- **empty-state**: Mensaje e ilustración para estados vacíos
