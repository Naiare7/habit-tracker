# services

Servicios Angular que centralizan la lógica de comunicación con el backend:

- **auth.service.ts**: Autenticación (registro, login, logout, token management)
- **habit.service.ts**: CRUD de hábitos
- **stats.service.ts**: Obtención de estadísticas y datos para gráficos
- **notification.service.ts**: Notificaciones y alarmas del navegador
- **post.service.ts**: Posts de la comunidad
