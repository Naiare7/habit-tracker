# pages

Componentes que representan páginas completas (vistas asociadas a una ruta):

- **login**: Pantalla de inicio de sesión
- **register**: Pantalla de registro de usuario
- **dashboard**: Vista diaria con hábitos y progreso
- **stats**: Pantalla de estadísticas y gráficos
- **community**: Pantalla de comunidad/chat
- **profile**: Pantalla de perfil y alarmas
